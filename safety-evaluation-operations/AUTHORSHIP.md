# Authorship and Tool Use

This is an independent portfolio case study created for Clare Jordan.

The work was developed through a human-led, AI-assisted process. Clare supplied the professional context, target role, constraints, prior work history, and the requirement that the result be accurate, non-confidential, reproducible, and complete. AI tools assisted with drafting, coding, consistency checks, and implementation speed.

The public artifact is explicit about what is synthetic and what it can and cannot prove. It does not claim access to proprietary systems, production trust-and-safety data, or confidential employer information.

Before using this project in an interview or assessment, Clare should be able to explain and independently defend:

- why a critical failure blocks launch despite aggregate improvement;
- how the paired SQL identifies a regression;
- why reviewer disagreement creates an adjudication task;
- which assumptions would need to change for production use;
- what human judgment is preserved at each step.

This disclosure is included because thoughtful AI collaboration is compatible with authentic work only when the candidate understands, verifies, and owns the result.
